# Simple Calculator (CLI)

A simple and professional Command Line Calculator built using Python.  
This application performs basic arithmetic operations with proper input handling and error validation.

---

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Invalid input handling
- Division by zero validation

---

## Technologies Used

- Python 3

---

## Project Structure

simple-calculator/
│
├── calculator.py
└── README.md

---

## How to Run

1. Open terminal or command prompt

2. Navigate to the project folder

cd simple-calculator

3. Run the program

python calculator.py
